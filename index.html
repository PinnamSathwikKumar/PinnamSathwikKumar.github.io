// manifesto.md

          
three rules I keep returning to...

        

        

          

            
tenet_01

            
Privacy is a product feature, not a footnote.

            

              If a model can run on the user's device, it should. EduMate began
              here.
            

          

          

            
tenet_02

            
Agents should do work, not just chat.

            

              A useful agent finishes a task. A demo agent finishes a sentence.
            

          

          

            
tenet_03

            
Ship small models close to the user.

            

              Speed, cost, and trust all compound when inference happens at the
              edge.
